## About
This repository contains a collection of C libraries, ranging from low-level data structures to higher-level parsing utilities.

### Goals:

- Improve my understanding of low-level programming in C
- Explore data structures and memory management
- Implement real-world utilities from scratch
- Build reusable components for personal projects

### Implemented Libraries
#### Data Structures
- Vector - dynamic array with automatic resizing capable of storing any data types
- String - mutable string implementation with automatic resizing

#### Parsing
- JSON Parser - Parses JSON data into an AST

### PLanned

- XML Parser
